# BenchSeed TPC-H Core

This crate provides the core data generator logic for TPC-H. It has no
dependencies and is easy to embed in any other Rust projects.

See the [docs.rs page](https://docs.rs/benchseed-tpch/latest/benchseed-tpch/) for API and the
the benchseed-tpch [README.md](https://github.com/Arnavsharma2/benchseed) for more
information on the project.
